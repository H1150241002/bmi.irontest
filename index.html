衛福部國民健康署 BMI 指標說明

BMI 核心概念

身體質量指數（BMI）是世界衛生組織及衛福部認可評估體重健康狀態的標準，由體重與身高平方之比值得出。

計算公式 BMI = 體重 (kg) ÷ 身高² (m²)

成人 BMI 分級基準

體位類別 BMI 範圍 (kg/m²) 健康影響
體重過輕 < 18.5 易骨質疏鬆、免疫力較弱
健康體位 18.5 ≤ BMI < 24.0 罹患慢性病風險最低
體重過重 24.0 ≤ BMI < 27.0 需著手微調飲食與增加活動
輕度肥胖 27.0 ≤ BMI < 30.0 三高與心血管疾病風險提升
中度肥胖 30.0 ≤ BMI < 35.0 建議尋求專業醫療團隊諮詢
重度肥胖 ≥ 35.0 極高健康風險，需積極治療
